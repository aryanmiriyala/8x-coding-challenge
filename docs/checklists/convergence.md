# Slice Convergence Prompt

- [ ] The user outcome can be demonstrated end to end.
- [ ] Acceptance and important failure/abuse examples have evidence.
- [ ] Relevant format/lint/type/unit/integration/E2E/build checks ran and results are recorded.
- [ ] Responsive, keyboard, loading, empty, and error states were inspected as applicable.
- [ ] Security/privacy/observability behavior matches the implemented boundary.
- [ ] New dependencies and migrations are justified and reproducible.
- [ ] Docs, traceability, risks, and decisions match reality.
- [ ] The implementation is recorded in small, reviewable commits; no slice file is accidentally left unstaged or uncommitted.
- [ ] Known gaps are explicit; no test or browser result is implied if not run.
- [ ] The next slice is chosen from evidence, not inertia.
